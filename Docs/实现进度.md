## 3. 已采用的可改默认值

- QQ 官方 WebSocket；当前采用沙箱，连接已验证。用户要求消息权限全部开放；未收到非 @ 事件前仍保留 `mentions` 能力声明，真实事件权限需联调核对。群白名单使用 OpenID。
- 私聊按平台／环境＋账号＋对方隔离，群聊按平台／环境＋账号＋群隔离；不跨群召回资料。
- 同会话串行，不自动合并／打断；不同会话最多 2 个轮次并行，最多等待 100 个任务。
- 统一的开发用人设；`deepseek-flash`；默认关闭思考模式，完整取得回复后发 QQ。
- 上下文 16000 字符预算、最近最多 50 条记录；模型输出最多 1024 token，最多 5 次模型步骤；输出按 1500 Unicode 字符分段。
- 时间工具只读；工具默认有副作用。失败和未知均不冒充成功。

这些是工程默认值，后续按大模块讨论可改，不新增已确认产品需求。

## 4. 技术基线与复用边界

- 锁定 `cordis@4.0.0-rc.10`、`@tencent-connect/qqbot-nodejs@1.0.5`、`ajv@8.20.0`；TypeScript 5.9.3 编译，Node 22.23.2 作为当前验证及镜像基线。
- SQLite 使用 Node 内置实现，不增加独立数据库容器；Node 22 当前仍将其标为实验性，后续 NAS 验收核对兼容性。
- Cordis 发布的类型声明采用无扩展名内部引用；本项目选择 TypeScript `Bundler` 解析模式，源码运行时引用均显式写 `.js`，编译后直接由 Node ESM 执行，不增加打包器或修改上游包。
- 外部插件直接使用 `@cordisjs/plugin-loader@1.0.0-rc.7`，匹配当前 Cordis 版本；小狼只补目录、配置、导出和启动状态检查。插件目录挂载在 `/app/plugins`，普通插件更新后重启生效，不重建镜像；HMR 未引入。
- 自有业务实现，没有复制 AstrBot、ChatLuna 或 Harness 的业务源码。QQ 官方 SDK 为锁定版本的直接依赖，平台协议代码仅位于接入插件内。参考官方协议、API 和前期调研；许可证尚未选择。
