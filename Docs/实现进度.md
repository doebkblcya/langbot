## 已经能做什么

| 能力 | 现在的情况 |
| --- | --- |
| QQ 文字聊天 | 已接入 QQ 官方机器人正式环境。私聊默认回复，群里 @ 或句中出现触发词时回复。私聊和群触发词消息已有真实收发记录。 |
| 接着当前聊天回复 | 读取当前聊天近期原文和较早摘要，结合全局人物与经历记忆。提示词包含当前北京时间、用户和来源群／私聊；仍使用临时人设。 |
| 图片处理 | 本条图片直接交给模型，收到图片即生成短描述；历史和摘要带逐张图片编号与描述，需要细节时按编号从 QQ 读取原图。原图由 QQ 托管，小狼不保存图片文件或跨请求原图缓存。 |
| 调用工具 | 已有模型选择工具、执行、继续生成回复的基础流程；已有查询时间、搜索记忆、查原文、明确记住／纠正／忘记，以及重看聊天图片的工具。 |
| 故障提示 | 处理失败时可在 QQ 提示中文原因、错误码和轮次编号；后台可查看对应记录。 |
| 管理面板 | 能看运行状态、聊天和过程日志，修改模型、QQ、触发和记忆配置；能查看、纠正、删除和置顶记忆，查看原文来源和每轮召回。保存后应用并重启生效。 |
| 插件管理 | 当前 16 个内置、2 个外挂插件全部列出；能看详情。内置无启停按钮，外挂可按依赖启停、编辑已声明的配置。触发规则在“消息触发”插件里修改。 |
| NAS 部署 | Docker 已运行，配置、插件和聊天记录都已迁移。用户发送“迁移测试”后，模型正常生成回复，QQ 返回发送回执。VPS 的小狼部署已清理。 |

### 持续完善

以下由助手结合当前功能和实际问题安排，不作为需要用户逐项确认的产品需求，也不表示现有基础能力全部缺失。

- 调度：维护排队、并发、取消、超时和任务状态；随主动／定时任务补持久化和恢复，避免重复执行。合并、打断等策略按实际需要处理。
- 发送与异常：维护分段、去重、回执和故障反馈，避免未知结果导致重复发送或重复工具操作。
- 数据与日志：维护现有聊天记录、故障记录和日志展示，针对实际问题修复。
- 后台与配置：随功能补充配置和查看入口，维护保存校验、错误提示和应用失败回退。保存后重启暂按现状保留。
- 插件维护：完善服务替换、依赖检查、状态展示和资源清理；不为了插件化无限细拆。
- 联调与发布：新增工具、群 @ 等路径在相关改动时完成必要验证；不为基础界面反复扩大测试范围。
