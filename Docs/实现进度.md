## 技术与验证基线

- Node.js 22.23.2，TypeScript 5.9.3；锁定 `cordis@4.0.0-rc.10`、`@cordisjs/plugin-loader@1.0.0-rc.7`、`@tencent-connect/qqbot-nodejs@1.0.5`、`ajv@8.20.0`。
- SQLite 使用 Node 内置 `node:sqlite`，此运行时仍显示实验性提示；没有单独数据库容器。源码 ESM，TypeScript 使用 Bundler 解析，输出由 Node 直接执行。
- 未复制 AstrBot、ChatLuna 或 Harness 的业务源码，直接复用官方基础库；Koishi／ChatLuna／Harness 插件不能直接互装。项目许可证尚未选定。
- 最近代码版本已通过 50 项离线测试、CI 构建及 Linux 无网络容器／HTTP 验证；[对应 CI](https://github.com/doebkblcya/xiaolang/actions/runs/38702863861)。本地不启动机器人或真实 HTTP 服务。
- 真实证据包括私聊 `hello` 与“日志测试”的完成轮次和平台回执、重启重新连接及历史保留、四个后台页面可访问。正式群非 @ 接收来自用户反馈；不扩大成未进行的完整验收。

测试按改动风险和实际问题选择，基础界面只做必要检查，不重复跑全量或扩大无关测试范围。本轮文档整理只核对内容、内部链接和 Git 差异，不构建镜像、不部署。
