| 上下文 | 按会话隔离；保留说话人；固定触发输入边界；统一临时人设；整组裁剪工具历史。 | 字符预算是保守长度控制，不是精确 token 计数；长期 Memory 和摘要未实现。 |

| 发送 | 纯文本消息段、Unicode 拆分；发送意图、逐段回执和已交付上下文；发送确认和可见记录在本地事务中写入。 | 结果未知不重发；部分成功只记已确认文字；不保证远端与本地的绝对一次。 |
| 恢复 | 保存历史、草稿、工具与发送状态；重启标注中断、未知，不自动重放。 | 去重记录暂无定期清理；容量、留存和管理查看后续补充。 |
| 故障可见性 | 结构化阶段／错误代码，不记录密钥、完整提示词或思考内容到普通日志。 | 当前错误记录到日志和数据库，尚未加入统一的 QQ 故障提示；未知结果需要人工核查。 |
| 部署材料 | Dockerfile、仅小狼的 Compose 示例、Linux CI。 | 未创建容器、端口、网络或 NAS 目录；未选择专用 NapCat 镜像及完整部署配置。 |

工具不逐次审批；其实际可执行范围取决于注册工具，而不是模型任意输出命令。副作用工具一旦执行后失败或超时，保守标为未知并结束本轮，不让模型自动重试同一操作。只读工具可把普通失败返回模型，在剩余预算内继续处理。

## 3. 已采用的可改默认值

- 正向 WS；样例群列表为空表示所有群，账号与地址需要 NAS 配置。
- 私聊按账号＋对方隔离，群聊按账号＋群隔离；不跨群召回资料。
- 同会话串行，不自动合并／打断；不同会话最多 2 个轮次并行，最多等待 100 个任务。
- 统一的开发用人设；`deepseek-flash`；默认关闭思考模式，完整取得回复后发 QQ。
- 上下文 16000 字符预算、最近最多 50 条记录；模型输出最多 1024 token，最多 5 次模型步骤；输出按 1500 Unicode 字符分段。
- 时间工具只读；工具默认有副作用。失败和未知均不冒充成功。

这些是工程默认值，后续按大模块讨论可改，不新增已确认产品需求。

## 4. 技术基线与复用边界

- 锁定 `cordis@4.0.0-rc.10`、`ws@8.22.0`、`ajv@8.20.0`；TypeScript 5.9.3 编译，Node 22.23.2 作为当前验证及镜像基线。
- SQLite 使用 Node 内置实现，不增加独立数据库容器；Node 22 当前仍将其标为实验性，后续 NAS 验收核对兼容性。
- Cordis 发布的类型声明采用无扩展名内部引用；本项目选择 TypeScript `Bundler` 解析模式，源码运行时引用均显式写 `.js`，编译后直接由 Node ESM 执行，不增加打包器或修改上游包。
- 外部插件直接使用 `@cordisjs/plugin-loader@1.0.0-rc.7`，匹配当前 Cordis 版本；小狼只补目录、配置、导出和启动状态检查。插件目录挂载在 `/app/plugins`，普通插件更新后重启生效，不重建镜像；HMR 未引入。
- 自有业务实现，没有复制 AstrBot、ChatLuna 或 Harness 的业务源码。参考官方协议、API 和前期调研；许可证尚未选择。
