# 小狼需求记录

更新日期：2026-10-15。本文只记录产品方向、用户已确认的要求和待讨论事项；工程流程见 [主链路](主链路.md)，实际完成情况见 [实现进度](实现进度.md)。

## 当前方向

小狼是个人定制、轻量克制、拟人化的 QQ 聊天机器人，计划开源。先把文字主链路用顺，再按模块增加能力；不为了通用性预建复杂体系。

以下为用户已确认的决定：

- 使用 **TypeScript＋Cordis 4** 自行编写完整项目，参考成熟实现并复用合适的基础库。AstrBot、Koishi、ChatLuna 和 DeepSeek Harness 是参考，不是必须运行的宿主。
- 借鉴 Harness 的插件化思想：主链路本身也可组合、替换，后续模块像积木一样接入。Cordis 负责服务依赖和生命周期，不自研另一套插件内核。
- 仅采用 **QQ 官方机器人＋WebSocket，直接使用正式环境**；在自己的测试群联调。不再实现 OneBot／NapCat 接入，不改动原有 AstrBot／NapCat。
- 模型选择 DeepSeek V4.1 Flash，当前实际 API 标识为 `deepseek-flash`。使用一个统一人设，不做多种人设。
- Mac 用于开发，不运行机器人；使用 Linux Docker 运行。当前运行于飞牛 NAS，已从临时验证用的美国 VPS 迁移；VPS 停止并保留回退。
- 初期方便自己扩展，不建设第三方插件市场，不额外增加多平台目标。

## 九个功能模块

| 模块 | 用户已确认的范围 | 尚需按模块讨论的细节 |
| --- | --- | --- |
| 触发与调度 | 私聊普通消息默认回复；群聊 @ 自身或出现称呼／触发词即触发。词出现在句中也算，包括只是在谈论机器人。主动插话必须有独立开关；定时与主动消息归此模块。 | 排队、合并与打断的体验；主动开关范围与策略；具体定时场景。 |
| 统一人设与回复生成 | 所有群共用一个人设，回复自然、克制。 | 后续做完整人设插件，并与自学习材料协作；当前仅临时 System Prompt，本轮不改。 |
| 规划与自动工具调用 | AI 自主选择并执行已接入工具、脚本、Skill 等，无需逐次确认。 | 首批实用工具；MCP／Skills／脚本的接入与执行范围。工具循环不等于这些协议已经实现。 |
| Memory | 跨会话、持久化记忆；知识、人物信息、长期记忆与历史回想统一归入此模块。能通过对话纠正和删除记忆。 | 写入与召回策略、跨群共享范围、查看与纠错方式。最近聊天历史不等于长期 Memory。 |
| 图片处理 | 使用支持图片输入的模型直接理解图片，结果进入上下文。 | 图片取得、请求格式、缓存和失败处理；目标模型视觉能力的端到端联调。 |
| 自学习 | 按设定时间学习聊天内容，按需记录、更新，例如学习语言风格。 | 来源、更新对象、周期、效果评估和生效方式；尚未确认自动生效。 |
| 简单插件扩展 | 能方便增加、修改、替换、停用模块。 | 随实际模块补充必要扩展点；不预建市场或复杂热更新。 |
| 表情包收集与选用 | 自动收集，在适当场景选用；参考已有插件机制。 | 收集与选用策略、频率、图库共享，以及具体参考项目。 |
| 基础管理界面 | 跟随已实现能力增加管理入口。先做只读面板，随后明确优先支持回复模型与 QQ 接入的查看、编辑，原 VPS 使用 SSH 转发；迁到 NAS 后按用户选择改为局域网直接访问。 | 已追加：所有实际插件均列出，按镜像内置／挂载外挂区分；内置不显示启停按钮，外挂可按依赖启停、注册配置后编辑。归属后续可调整；当前不删除插件代码或数据。 |

语音、注意力与行为学习、电脑操作暂不做。自学习任务可由调度启动，产出供 Memory 或回复使用，不意味着各模块必须共用一种存储或算法。

## 工程默认值与需求的区别

FIFO 排队、并发数、上下文长度、思考模式、重试和超时等，是助手为第一版采用的**可改工程默认值**，不是用户逐项确认的产品要求。当前数值集中在 [实现进度](实现进度.md)，执行行为集中在 [主链路](主链路.md)。

触发词当前按直接文本匹配，引用原文、OCR、@ 全体不算触发；群历史隔离、暂不跨群召回。这些现有行为可以按模块讨论调整。

## 后续推进方式

1. 先整理方向和现有主链路体验，记录需要微调的具体行为；文档整理已完成；模型／QQ 配置已完成；当前补故障反馈、触发插件和插件管理。
2. 按大模块集中讨论，不逐个追问简单参数，不重复确认已知要求。
3. 简单主链路修改可以攒成一批：本地修改、必要验证、统一构建镜像，再部署到当前运行宿主机。外挂插件和配置更新是否需要镜像，按实际改动边界判断。
4. 基础改动只做必要验证，避免重复全量测试和无关扩展。环境、消息范围、模型、端口等影响使用的选择必须主动说明。

新增功能的先后顺序仍待讨论；尚未决定立即开发 Memory、图片或其他模块。项目许可证也尚未选择。
